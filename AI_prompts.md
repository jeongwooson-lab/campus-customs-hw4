# AI prompt log

The assignment was supplied as one document and the main request was: “Work through Problems 1–13 following the instructions, using ordinary college-student English.” The short prompts below are my own problem-by-problem restatements used to guide this build. They are not presented as thirteen separate messages from the student. Problem 6 was absent from the supplied text, so I did not invent its requirements.

## Problem 1 — Vibe coder prompts
Working prompt: Keep a readable log of the assignment goals in my own words as I build, with one section per problem.

## Problem 2 — Analyze the database
Working prompt: Inspect every shop table and explain what each field contributes to the catalogue, stock checks, accounts, and chat memory.

## Problem 3 — Build the website
Working prompt: Make a React and Vite store with the main navigation, original Yale-inspired copy, real product cards, detail pages, and a floating chat panel.

## Problem 4 — Account and login
Working prompt: Let shoppers register with their name, email, and password. Store only a password hash, and make the seed account and a new account work.

## Problem 5 — PydanticAI backend
Working prompt: Build FastAPI routes around a PydanticAI shopping agent with separate prompt, model, tool, and wiring files.

## Problem 6 — Not included in the supplied text
No prompt can be logged accurately because the assignment file skips directly from Problem 5 to Problem 7.

## Problem 7 — Chat search updates the page
Working prompt: Return matched product records in a structured chat response, then render cards that still link to their detail pages.

## Problem 8 — Customer memory
Working prompt: Save authenticated chat messages, reload them after login, and pass the current shopper and product page to the agent.

## Problem 9 — Usability improvements
Working prompt: Add product search and category/price controls on the front end, plus exact catalogue lookup and a grounded fallback on the backend.

## Problem 10 — Style the website
Working prompt: Give this store a distinct Yale-inspired visual system with strong type, editorial sections, product imagery, and a friendly chat experience.

## Problem 11 — Site testing
Working prompt: Check the actual site in a browser and capture inventory, chat-result cards, and product-filter screenshots with clear captions.

## Problem 12 — Audit, safety, and harness
Working prompt: Keep agent activity records across runs, put safety rules in the system prompt, and explain the fields, tools, and run settings.

## Problem 13 — GitHub delivery
